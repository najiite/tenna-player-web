FFmpeg (desktop apps)

The Windows and Mac apps include unmodified, ready-built copies of FFmpeg 6.1.1, taken from the ffmpeg-static project's release. FFmpeg is licensed under the GNU General Public License, version 3 or later (GPL-3.0-or-later).

Tenna runs FFmpeg as a separate program on your computer, only to convert audio the built-in player cannot decode and to read the subtitle tracks of films. It is not linked into Tenna. The licence text and the readme for the exact build are installed with the app, in the ffmpeg folder inside the app's resources.

You can get FFmpeg's source code from ffmpeg.org. If you would like the source that matches the build in a Tenna download, ask us on GitHub and we will point you to it.
