Which Mac do I have? Open the Apple menu and choose About This Mac. If it says Chip: Apple M1 (or M2, M3, M4…), download the Apple Silicon file. If it says Processor: Intel, download the Intel one.

The Intel file also runs on an Apple Silicon Mac, but through a translation layer that makes it far slower, so use the right one.

Installing

Three minutes, start to finish.

Tenna's installers are not code-signed yet, so Windows and macOS will ask you to confirm once. That is expected.

  1. Download and run

    Open Tenna-IPTV-Player-Setup.exe from your Downloads folder.

  2. Confirm the warning

    If "Windows protected your PC" appears, choose More info, then Run anyway. It shows because the installer is not signed yet.

  3. Install and open

    Pick a folder if you like, finish the installer, and open Tenna from the Start menu. Then add your playlist.

  1. Open the disk image

    Double-click the .dmg and drag Tenna IPTV Player into the Applications folder.

  2. Open it the first time

    In Applications, right-click the app and choose Open, then Open again. After that it opens normally.

  3. If it says "damaged"

    That is macOS blocking an unsigned download. In Terminal, run xattr -cr "/Applications/Tenna IPTV Player.app" and open it again.
